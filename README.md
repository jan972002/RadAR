# RadAR
Goal of the project is to create smallest possible device able to map it's surroundings!
This particular one was built using scraps left after another project.

Materials:
- 2x Servo Power HD 1810MG
- Lidar Beewake TF-Nova
- ESP 32 WROOM 32 Dev Kit
And a bunch of scrap cables :D

Basic funcions can be used from python script level.
As shown on the image below, your result is gonna look like point coud. You can use Post-FX alorythms build in app or create your own.

GUI module is able to save your scans in .npy .png .rr and .obj formats

.obj save is broken at the time of writing this readme. .rr format is custom file format based on .npy array format. 

GUI and low level code were written in polish. I'm not planning to make english translation. For estended command list of low level communication type /help in gui!

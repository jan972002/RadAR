# RadAR
Goal of the project is to create smallest possible device able to map it's surroundings!
This particular one was built using scraps left after another project.

Materials:
- 2x Servo Power HD 1810MG
- Lidar Beewake TF-Nova
- ESP 32 WROOM 32 Dev Kit
And a bunch of scrap cables :D
